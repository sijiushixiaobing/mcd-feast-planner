能力清单

📍

门店定位

按城市/商圈查可点餐门店，按距离择优，方案注明店名与门店编码。

📖

菜单拉取

拉全店在售菜单（实测 108 个餐品 / 15 个分类），优先套餐与多人餐。

🎫

三重用券检查

门店券 + 卡包券 + 麦麦省待领券，一个不漏。

✅

🧮

原价/优惠/实付/人均，超预算自动降档换组合。

📋

160 个餐品营养数据，控卡人群友好。

开发踩坑（集成经验）

① query-nearby-stores 的 city 与 keyword 必须同时传，只传 city 返回 600058「城市名或者关键词不能为空」。
② 到店自取场景（beType=1）不要传 beCode，传了 query-meals / query-meal-detail 会报错。
③ query-my-coupons 返回的券含已过期的，不能直接当可用券用——实测一张「11.9元麦辣鸡腿堡」卡包券经 calculate-price 返回 600012「此卡券不在使用日期内」。
④ calculate-price 的券要挂在具体商品项（couponId + couponCode），不支持整单挂券。

安全与合规

· 只读 + 算价：不调用 create-order / cancel-order / mall-create-order / party-order-create / auto-bind-coupons 等任何写操作，下单与付款由用户在麦当劳官方渠道完成。

· 无凭证泄露：Token 只走环境变量 MCD_MCP_TOKEN，仓库与页面内无任何真实凭证。

· 无编造数据：菜单、价格、优惠券全部以 MCP 实时返回为准。
